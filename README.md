# Boud Afsar

A fast-paced, Neo-Brutalist Kashmiri arcade mosquito-hunting web game built with vanilla HTML5 Canvas, CSS, Web Audio API, and optimized `.webp` sprites.

## Features
- **Exact Drag-to-Aim & Release-to-Shoot Gameplay**: Hold and drag anywhere on mobile or desktop to project a high-contrast dashed aim line and rotate the blaster; release to fire a heavy blast shot.
- **Neo-Brutalist UI**: Bold onboarding loading screen, crisp HUD, Start/Pause cards, and tactile controls layered over an illustrated Kashmiri street backdrop.
- **Custom Audio Engine**: Synchronized heavy blast shot SFX, custom hit/miss audio clips with automatic leading-silence trimming, and fade-in/fade-out mosquito flight audio.
- **Zero Build Dependencies**: Pure static web app (`index.html`, `styles.css`, `game.js`, `audio.js`, `assets/`) ready for instant hosting on GitHub Pages, Vercel, Netlify, or Cloudflare Pages.

## Run Locally
```bash
python -m http.server 8080
```
Open http://localhost:8080 in your browser.
